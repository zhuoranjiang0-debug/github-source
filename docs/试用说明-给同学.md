# 试用说明（发给同学）

> 目的：让**完全没接触过这个项目的人**能自己跑起来，并且把有用的反馈带回来。
> 这份东西以后就是结题材料里"用户测试"那一节的原型。
>
> 发给同学的是这一份：`build\AI2D-试玩包-2026-09-19.zip`（约 85 MB）。
> 压缩包里的 `使用说明.txt` 就是下面第二段的内容，改的时候两边一起改。

## 一、先发这条消息（直接复制）

```
xx，帮我个忙，试用一下我做的工具，大概 15 分钟 🙏

这是我在做的项目：一个给不会写代码的人做手机小游戏的工具。
我做了个示例小游戏，还有一个可视化编辑器，想找个没接触过的人试试。

压缩包我已经打包好了，你只要三步：
1. 解压到桌面上（一定要先解压，别在压缩包里直接双击）
2. 双击「开始游戏.bat」先玩一会儿
3. 再双击「打开编辑器.bat」，照着压缩包里的《使用说明.txt》做几步

有 bug 很正常，别客气。哪儿卡住了直接说，能截图最好。
我主要想知道：哪一步不知道点哪儿、哪里看起来像坏了、哪句话看不懂。
```

## 二、压缩包里的《使用说明》

```
【第一步：解压】
把整个压缩包解压到一个普通文件夹里（比如桌面）。
⚠ 一定要先解压，直接在压缩包里双击 .bat 是打不开的。
⚠ 解压出来要保留文件夹结构，别只把其中几个文件拖出来。

【第二步：玩游戏】
双击  开始游戏.bat
  · 左右方向键：移动
  · 空格 / 点画面空白处：跳
  · 吃金币加分，碰到红色的刺掉血，血没了就输，金币吃光就赢
  · 玩完按 R 重开；按 Esc 会进到编辑器
  · 想退出直接关窗口

【第三步：玩编辑器（这才是这个项目真正的东西）】
双击  打开编辑器.bat
  1. 从底部一排里，按住「金币」拖到画面上松手 —— 看是不是多了一枚金币
  2. 点一下那枚金币，右边面板里改颜色、改大小 —— 看画布上是不是立刻变了
  3. 按 F5 试玩 —— 你刚放的金币在不在？按 Esc 回来
  4. 点顶栏「逻辑」，点左边第 4 条「按住跳跃键跳起来」
     · 上面蓝条那句中文，念的就是这条规则的意思
     · 把「哪个键」的下拉从「跳跃」改成「往左走」—— 那句话应该立刻跟着变
     · 按 Ctrl+Z 撤销，变回来
  5. 按 Ctrl+S 保存 —— 会提示"内置示例，已另存为"

【第四步：告诉我你的感受】
报告格式（照着填）：
  第几步：
  做了什么：
  期望看到：
  实际看到：
  重来一次还这样吗：

【打不开怎么办】
最常见的原因：没解压就双击、或者被杀毒软件拦了。
还是不行就把整个窗口截图发我，别自己折腾。
```

## 三、发之前，你（项目负责人）要确认的三件事

1. **发的是压缩包，不是文件夹里散着的文件。** 微信/QQ 传文件夹容易漏文件，
   而漏掉 `Godot_v4.6.1-stable_win64.exe` 或 `app/` 就直接打不开。
2. **别发仓库里那个 `AI2D-Game-Creator-2026-09-19.zip`。**
   那个是"只给源码"的版本（0.8 MB）：里面没有引擎、没有中文字体，
   而且日期是旧的。同学拿到只会看到"找不到引擎"。
3. **确认对方用的是 Windows。** 这个包是 Windows 专用的。
   对方是 Mac 的话跑不了，换手机版：把 `build\android\ai2d-debug.apk`
   发给他，安卓手机/平板点一下就能装（装之前要在设置里允许"安装未知应用"）。

## 四、收到反馈之后怎么用

- 反馈按"第几步"记下来，直接补进 [测试清单.md](测试清单.md) 的「测试记录」表，
  那一节以后就是结题材料里的测试报告。
- **他卡住的地方比他说的话值钱。** 不要提前给他讲界面怎么用——
  讲了他就没有卡住的机会，而卡住的地方恰好是我们该改的地方。
