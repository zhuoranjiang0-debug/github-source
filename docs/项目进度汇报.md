# 项目进度汇报

**截至 2026 年 9 月 20 日**

## 一句话

AI2D Game Creator —— 在手机上做 2D 游戏原型的小工具。
目前**编辑器、运行器、逻辑编辑器、移动端都已完成并实测通过**：
能在手机上从零做出一个能跑的小游戏，**全程不写一行代码、不碰一行 JSON**，
做完直接装到安卓平板上玩。

**范围说清楚**：现在只做**横版动作 / 平台跳跃类原型**（跑跳、重力、碰撞、敌人、
道具、计分胜负、多关卡）。格子类（贪吃蛇、俄罗斯方块）、弹球类（打砖块）、
卡牌类暂不承诺 —— 但架构上留了扩展位，详见 README 的「扩展契约」。

## 现在能做到什么（可以现场演示，大约两分钟）

1. 双击 `打开编辑器.bat`，打开编辑器
2. 从底部素材栏**拖**一枚金币到画布上
3. 在右侧属性面板里**改它的颜色、大小、位置**
4. 点顶栏「**逻辑**」，新建一条规则：
   > 当「小恐龙」碰到「金币」时，就把「小恐龙」的「分数」增减 1，删除对方

   这一句不用写——从下拉框里选事件、条件、动作，表单自动生成。配完之后界面会把这句话**读回给你看**，一眼知道配得对不对。
5. 按 **F5** 立刻试玩，真的能玩
6. 按 **Ctrl+S** 保存，下次打开接着改

**在平板上**：双击 `构建安卓包.bat` 产出安装包，装到安卓平板上，画面铺满整屏，
左下角三个屏幕按键（左 / 右 / 跳）都能用；按键也可以自己加、自己改绑定。

**改「这一类」**：点底部素材栏里的一项，就能改这一类对象共有的东西 ——
名字、标签、颜色、原始大小、碰撞、会不会动。改一处，场上同类对象一起变；
自己单独设过的那些不受影响，面板会写清有几个。

## 怎么自己跑起来

1. 拿到整个项目文件夹
2. 确认根目录有 `Godot_v4.6.1-stable_win64.exe`（没有的话去 godotengine.org 下载同名版本）
3. 双击 `打开编辑器.bat`
4. 想做点别的操作，看 `docs/文件导览.md`

**先读哪份文档**：

- 只想看看这是什么 → 你正在读的这份
- 想读懂代码 → `docs/ARCHITECTURE.md`（为什么这么设计）+ `docs/DATA_MODEL.md`（数据结构）
- 想知道为什么做了某些取舍 → `docs/决策记录.md`
- 想快速上手改代码 → 从 `app/src/runtime/rule_engine.gd` 开始，那是核心
