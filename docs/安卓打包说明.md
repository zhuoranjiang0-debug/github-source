# 安卓打包说明

打完的包在 `build\android\ai2d-debug.apk`，约 34 MB。
双击 `构建安卓包.bat` 可以重新打。

## 装到平板上

1. 把 APK 传到平板（微信、数据线、网盘都行）
2. 在平板上点开它
3. 系统会提示"不允许安装未知来源应用"——按提示去设置里**允许这个来源**，再点一次
4. 装好后桌面会出现 **AI2D Game Creator**

首次打开会有一小段加载，属正常。

## 一次性准备（已经做过了）

打包需要一套安卓工具链，放在桌面的 `android-tools` 文件夹里：

| 内容 | 用途 |
| --- | --- |
| `jdk\` | Java 运行环境（安卓打包工具依赖它） |
| `sdk\` | 安卓 SDK：`platform-tools`、`build-tools`、平台 34/35 |
| `debug.keystore` | 调试签名，`别名 androiddebugkey / 口令 android` |

Godot 通过 `%APPDATA%\Godot\editor_settings-4.6.tres` 找到它们。

## 几个踩过的坑（别重复踩）

### 1. 不开 Gradle 构建

开了 Gradle 就要下载 Gradle 本体（130 MB）和几百 MB 依赖。
实测 Gradle 官方源、Google Maven、Maven Central 在国内只有 **20~50 KB/s**，
那要等好几个小时。

关掉之后用导出模板里现成的 APK 外壳，十秒钟打完，同样能装能跑。
代价是不能自定义安卓工程（改包名、加原生插件、改权限）。

### 2. 必须开 ETC2/ASTC 纹理压缩

`project.godot` 里的 `textures/vram_compression/import_etc2_astc` 必须是 true。
不开的话安卓导出直接判定"配置无效"，**而且不报任何原因** ——
Godot 源码里那一处只把校验结果设成 false，没写错误信息。
当时对着一个空白的报错查了很久。

### 3. Android 构建模板和版本标记

即使不开 Gradle，Godot 也会检查 `app/android/build/build.gradle` 是否存在，
以及 `app/android/.build_version` 里的版本号是否和当前引擎一致。

这两样是从导出模板的 `android_source.zip` 里来的：

```
解压 android_source.zip  →  app/android/build/
写 app/android/.build_version，内容是 4.6.1.stable
```

`app/android/` 有 200 MB，已加进 `.gitignore`，不进版本库。

### 4. 包名和项目名

项目名 `AI2D Game Creator` 带空格，不符合安卓包名规范。
所以导出配置里显式写了 `package/unique_name = "com.ai2d.gamecreator"`。

## 重新安装工具链（如果换了电脑）

1. 下载 JDK 17（Adoptium，免安装版 zip）解压为 `android-tools\jdk\`
2. 下载 Android 命令行工具，解压到 `android-tools\sdk\cmdline-tools\latest\`
3. 装组件：
   ```
   sdkmanager --sdk_root=<sdk> --licenses
   sdkmanager --sdk_root=<sdk> platform-tools build-tools;34.0.0 build-tools;35.0.0 platforms;android-34 platforms;android-35
   ```
4. 生成调试签名：
   ```
   keytool -keyalg RSA -genkeypair -alias androiddebugkey -keypass android ^
     -keystore <tools>\debug.keystore -storepass android ^
     -dname "CN=Android Debug,O=Android,C=US" -validity 9999 -deststoretype pkcs12
   ```
5. 在 Godot 的编辑器设置里填上这三条路径：
   `export/android/android_sdk_path`、`export/android/java_sdk_path`、
   `export/android/debug_keystore`
