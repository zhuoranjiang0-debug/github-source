## 怎么用

你只要开口说一句话，我来动手：

| 你想干的事 | 怎么说 |
| --- | --- |
| 回到某个存档去看一眼 | "回到改规则按键之前的那个存档" / "回到 9 月 19 号那个存档" |
| 看完回到最新的 | "回最新" |
| 记不清有哪些 | "列一下所有存档" |
| 存一个新的 | "存个档"（我会补一行进这张表） |

**不用担心说错。** 你说的话和哪个存档对得上，我心里有数；对不上我就把清单念给你听，让你挑。

**这张表不是你能回到的全部。** 每一次改动都留在 git 里，带一句人话说明，
所以"回到删词汇表之前""回到加 AI 助手之前"这种更细的位置一样能回。
你只要描述大概是什么时候、改的什么事，我去找。

## 关于"存档"这件事本身

- 存档 = 在书里夹一个书签，**不是**把后来的东西删掉。这之后写的东西都还在，可以在新旧之间来回翻。
- 存的是什么：那一刻的**全部工程文件和文档**（代码、说明、示例）。构建产物（安卓包、网页版）不在里面，所以重要的包会另外留一份副本，写在上面那张表里。
- 什么时候值得存：**动一个"有点心虚"的改动之前**。比如这次——要改的是规则面板，万一改完发现不如原来好用，一句话就能退回来。
