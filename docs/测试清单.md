# 测试清单

> 照着走一遍，大约 15~20 分钟。
>
> 这份清单有两个用途：现在用来找问题；
> 以后做用户测试时，它就是脚本，跑出来的结果直接进测试报告。

## 怎么报问题

按这五行说，基本不用来回问：

```
第几步：
做了什么：
期望看到：
实际看到：
重来一次还这样吗：
```

最后一行最有用——**能稳定重现的问题，和偶发的问题，修法完全不同。**

## I. 规则里的按键（改成下拉了）

以前规则里要手打 `ui_accept`，看不出那是屏幕上哪个键，打错了还不报错。现在改成点着选。

| # | 做什么 | 应该看到 |
| --- | --- | --- |
| I1 | 点顶栏「逻辑」，左边点开「按住左方向键向左移动」 | 条件那头写着「按住按键」，下面一行是「**哪个键**」，右边是下拉框，写着「往左走」 |
| I2 | 点开那个下拉框 | 选项是人话：往左走 / 往右走 / 往上走 / 往下走 / 跳跃 / 返回 / 选择 |
| I3 | 换成「跳跃」，看上面那行蓝条里的话 | 立刻变成「正按住「跳跃」」——**面板和句子说的是同一个词** |
| I4 | 按 `Ctrl+Z` | 变回「往左走」 |
| I5 | 点开「松开方向键就停下」 | 两个条件右边都勾着「反向（不满足）」，句子念的是「**没有**按住「往左走」、**没有**按住「往右走」」 |
| I6 | 把其中一个「反向」勾去掉 | 句子跟着变回「正按住」——念的和做的应该始终一致 |
| I7 | 点开「按空格跳跃」，看「哪个键」 | 那里列的是键盘上的键（空格 / 回车 / Esc / 字母），和上面那张动作表是两回事 |

> 为什么"两个下拉表"不是一回事：**动作**（跳跃）是屏幕按键按下去也会触发的，
> **键盘实体键**（空格）只有真按键盘才触发。所以手机上的跳跃要配「按住 → 跳跃」，
> 而不是「按下 → 空格」——这正是平板实测里跳跃键没反应的原因。

以前颜色、碰撞、会不会动这些**只能按一个个对象改**，想把"整类金币"都改掉就得点五遍。
现在点素材栏里的一项，就能编辑这一类。

| # | 做什么 | 应该看到 |
| --- | --- | --- |
| M1 | 点底部素材栏里的「金币」 | 右边面板换成紫色标语：**「正在编辑「金币」这一类」**，下面写「场上摆了 5 个」和内部名 `ent_coin` |
| M2 | 看分组 | 三组：**基本**（名字、标签）/ **外观**（颜色、原始大小）/ **物理**（会动吗、碰撞） |
| M3 | 改「名字」成「金币子」，按回车 | 素材栏那一项、画布上的对象名、规则里念出来的句子**一起变** |

## L. 「会动吗」与配错规则的提示（这次新增）

起因：用户给 AI 生成的小怪配了「设置速度」，小怪**纹丝不动**。

### L-1 让一个对象动起来

| # | 做什么 | 应该看到 |
| --- | --- | --- |
| L1 | 点画布上任意一个**静止**的东西（比如尖刺） | 属性面板里多出一节「**会动吗**」，下面一行小字写着"跟随类型：静止不动（会挡住别的对象）" |
| L2 | 把「会动吗」换成「**会动 · 受重力（会掉的）**」 | 小字变成"已单独设置：会动、会往下掉"；按 `F5`，它**真的会掉下去** |
| L3 | 换回「跟随类型」 | 它又不动了（回到类型上写的值） |
| L4 | 新建一条规则：事件「每一帧」+ 动作「设置速度」，对象选**那个对象**，水平速度填 2 | 试玩时它开始横向移动 |
| L5 | 再让 AI 生成一个**飞行**小怪（写「一个会飞的紫色小怪」） | 草稿里会写"它是会动的（飘着、不往下掉）"；生成出来的这只**开箱就能配速度**，不用先改属性 |

> 提醒：**「设置速度」只对"会动"的对象有效**。静止对象不参与物理步进，
> 设了速度也不会动。要让静止的东西动起来，两条路：
> ① 在「会动吗」里改成"会动"；② 或者改用「移动」这个动作（直接挪位置，
> 但它不参与物理，会穿过墙）。

### L-2 配错的规则会被标出来

| # | 做什么 | 应该看到 |
| --- | --- | --- |
| L6 | 新建一条规则，事件选「**每一帧**」，加一个动作，对象那一栏看有没有「自身」 | **没有**——换成一句说明："这个事件没有触发对象，所以没有「自身」" |
| L7 | 手改 JSON，硬把某个动作的 `target` 写成 `"self"`，再打开编辑器 | 左边清单里那条规则名字前出现 **⚠** 并变黄；右边句子下面写出原因："…里的「自身」指不到对象……这条规则不会生效" |
| L8 | 把事件换成「**发生碰撞时**」 | ⚠ 消失——碰撞是给得出触发对象的 |

### L-3 碰撞由你决定（每个对象单独设）

| # | 做什么 | 应该看到 |
| --- | --- | --- |
| L9 | 选中画布上的**地面** | 属性面板里多出一节「**碰撞**」，小字写着"跟随类型：地面（接得住掉落的东西）" |
| L10 | 把它改成「**普通障碍**」 | 小字跟着变；按 `F5`，掉下来的金币会**穿过这块地面**（原来的地面还在的别处落地） |
| L11 | 顺手看看：把所有地面都改成普通障碍之后 | 逻辑界面里那条掉落规则会被标 ⚠（"场景里没有任何「地面」，掉下来的东西会穿过一切掉出画面"） |
| L12 | 改回「跟随类型」 | 一切恢复 |
| L13 | 选中一枚**金币**，把「碰撞」改成「拾取物」 | 如果这个工程里金币原来是"普通障碍"，改完之后它就变成真正的拾取物（不挡人、只落在地面上） |

> 两条经验：**「会动吗」优先于「碰撞」**——会动的对象统一走"会动那一层"，
> 这样掉落物不会粘在会动的小怪身上；另外这些改动都是**只影响你选中的这一个**，
> 同类的其他对象不受影响（想整类都改，得等"编辑实体类型"那块做完）。

## 已知的粗糙处（不用报，我知道）

这些不是 bug，是还没做的功能：

- **不能新建工程，也不能另存为**——保存只会写到 `my-prototype.ai2d.json`
- **不能新建「实体类型」**——素材栏里只有示例里带的那 7 种。想做一种全新的对象（比如"会飞的敌人"），暂时得复制一个现成的再改，或者手改 JSON
- **按键只能从现成的复制**——跟上面同一个根因。工程里一个按键都没有时，暂时做不出第一个
- **按键上写什么字，跟的是绑定的动作**——绑「跳跃」就写"跳"。想让它写别的字（比如"开火"），得改实体类型的名字，还不能单个改
- **屏幕按键按下去，不会触发「按下按键时」这类规则**。屏幕按键的作用是"替你按住那个输入动作"，所以跟「按住」有关的规则都正常；但「按下按键时」是跟着真实键盘事件走的，手指按屏幕按键产生不了键盘事件。示例里左右移动和跳跃现在都走「按住」了，所以两边都能用；你自己再配新按键时，也要记得用「按住」而不是「按下」。
- **按住跳跃键会连着跳**。示例里跳跃是用「每一帧 + 正按住 + 站在地上」搭的，所以手指一直按着不放，小恐龙就会落地就再跳一次。想只跳一下，松开再按就行；真要"按一下才跳一下"，得给引擎加一种"按下某个动作时"的事件（记在决策记录的待定表里，暂时没做）
- **极低概率会"跳得特别高"**。平板实测时偶尔出现，触发条件没抓到；**用户判断暂时不修**（改动风险大于收益，演示时也看不出来）。已知：同一帧触发两次跳跃**不会**跳更高（跳跃是直接把速度设成同一个值），所以更像是"在空中又跳了一次"。哪天想查，最省事的办法是在跳跃时打一行日志，玩到出现为止
- **AI 现在只认得两种说法**：生成一个敌人（"一个会飞的紫色小怪"）、让天上掉金币（"每 2 秒掉一个金币"）。别的说法它会老实说没听懂，不瞎编。以后接上在线模型，认的范围才会大起来
- **AI 按钮里那个「填 key 变聪明」是灰的**：接在线模型排在 M4-c，还没做。放一个点不动的按钮是有意的——比藏起来、让人以为这工具就这点本事好
- **AI 生成的敌人不会自己动**：它是静止的危险物（碰到扣血）。想让它巡逻、跳动，得自己在逻辑界面加规则——草稿预告里也这么写了
- **AI 生成的画面还是彩色方块**：素材系统没做，这是 M4 之后的那一块
- **金币完全重叠时看不出有几枚**：这是"不互相挡"的代价，而"落点散开"用户明确说不做（要给引擎加"随机范围"，不值当）。所以一堆金币看起来就是一枚，碰到一次全部结算 —— 分数会告诉你其实有好几枚
- **金币只和「地面」碰**（尖刺、静止的怪、玩家、会动的小怪、别的金币都不碰）。所以**金币会从尖刺上方穿过去落到地面**。如果落点正好在尖刺站着的那块地面上，你过去捡仍然要挨那一下（那是尖刺的「碰到扣血」规则，跟碰撞无关）——想避免就把掉落规则的落点挪开，别对着尖刺
- **工程里必须有"地面"类对象**，否则掉下来的金币会穿过一切掉出画面。校验器会警告（`project.no_ground`），但「地面」这个身份写在类型上，界面上改不了 —— 只能手改 JSON，属于"不能编辑实体类型"那笔老账
- **「碰撞」这一项只能一个一个对象改**：想"整类金币都改成拾取物"，得逐个选中去改，或者手改 JSON 里的类型。整类编辑要等"编辑实体类型"那块做完
- **注意**：你自己那份工程里的「金币」类型还是旧的「普通障碍」（新示例已经标成"拾取物"了）。想让它变成拾取物，选中金币在「碰撞」里改一下即可
- **老工程会自动升级一次**：1.0 时代保存的工程打开时，带 `ground` 标签的「地面」会被自动认成"地面"，掉落物才接得住。但**其他的碰撞身份不会一起改**（比如那时金币写的是"普通障碍"）——想改就选中它、在「碰撞」里调
- **属性面板改不了"类型"**，只能改选中的这一个对象
- **非数值的自定义属性不能编辑**，会显示「此版本不可编辑」
- **画布上没有缩放手柄**，改大小只能在面板里输数字
- **不能删除关卡**，也不能新建关卡
- **焦点在属性面板的输入框里时**，Ctrl+Z 是"撤销刚打的字符"、Delete 是"删光标后面的字符"——这是输入框的正常行为，不是 bug。想撤销工程改动或删除画布上的对象，先按回车或点一下画布
